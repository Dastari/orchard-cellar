# Gear catalogue (design draft)

Generated by `npm run render:gear-catalogue -w @orchard/tools` from `packages/tools/src/gear-rig/catalogue.ts`. The same data drives names, tooltips, icons, paper-doll visuals and sell values.

## Naming grammar

| Rarity | Name pattern | Example |
| --- | --- | --- |
| Poor | {Damage} {Material} {Base} | Rusted Iron Arming Sword |
| Common | {Material} {Base} | Bronze Arming Sword |
| Uncommon | {Prefix} {Material} {Base} or {Material} {Base} {Suffix} | Steel Longsword of Fortitude |
| Rare | {Prefix} {Base} {Suffix} (material shown in the tooltip) | Radiant Bulwark of the Ages |
| Epic | {Lineage} {Base} | Dawnsworn Greathelm |
| Legendary | unique name | The Bonecrippler |

Prefixes grant a primary attribute or headline power (white lines). Suffixes grant a secondary stat, regeneration or a skill rank (green `Equip:` lines). Several items may share one icon or worn family; material, trim and rarity ornaments make them distinct.

## Open decisions

- **Authored combinations or rolled affixes?** Item stacks carry no per-copy data today. Either publish chosen combinations as distinct item ids (fits the current schema and trading), or add per-item affix storage for random rolls.
- **Attributes on gear.** Extend `EQUIPMENT_STAT_BUDGETS` to the six attributes, mana and regeneration, and show attributes to players.
- **Two-hand vs shield.** Staffs, polearms, warhammers and bows are listed as two-handed; decide whether the off-hand stays empty.
- **Missing worn art.** Caps and kettle hats need worn head designs; their icons already exist.
- **Icon choice.** Each base ranks its icon rows by measured ornateness (accent pixels × 3 + area ÷ 4); rarer items take the more ornate rows. 164 weapon rows and 185 armour rows are available.
