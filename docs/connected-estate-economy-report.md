# Connected estate economy: source model

Base bottle income stays 5000 bronze; first-bottle quest stays 50000. One base bottle plus that quest pays 55000, below the first expansion 60000. Two bottles plus the quest pay 60000 before any spending. Both sequential rooms cost 240000 combined. The former 3,200/4,200 prices each required one base bottle. New standalone equivalents are 12/36.

Each row funds one room independently; no quest grant, previous room or Vintage upgrade costs are subtracted. 3 bought apples cost 36 bronze per bottle input; this is not net profit. Station construction, ingredient availability, fuel/repair, hauling, travel and manual output clearing must be measured in a fresh-player journey. Ranked rows assume that Vintage rank is already purchased, so they are not fresh-character forecasts. No bottle, crop, order or quest price was reduced.
